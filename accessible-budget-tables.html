How to make budget tables accessible in PDF and HTML

A reader needs to know what each budget number represents. A table should identify its row and column headers so assistive technology can associate each value with the right labels. W3C recommends captions to identify tables and explicit header relationships where needed. W3C tables tutorial

Make the table easier to follow

Begin with the approved spreadsheet or report. For a simple budget comparison, use columns such as “Department,” “2026 adopted budget” and “2027 proposed budget.” State the units clearly: dollars, thousands of dollars or another unit.

Avoid using a table just to arrange unrelated text on a page. If one table contains several independent sections, consider splitting it into smaller tables with clear captions. Complex headers need careful associations; changing the visual layout alone does not create them. W3C tables tutorial

For an HTML version, use actual table markup and mark header cells as headers. Your website editor may offer these controls without requiring code. For a PDF version, inspect the exported table tags and their header associations. Export can lose structure, so check the output rather than assuming the source’s settings survived. Check meaning as well as formatting

Do not rely on red text alone to indicate a deficit. Preserve the minus sign, parentheses or an explicit text label, and explain the convention. Information should remain understandable without relying only on color or other sensory characteristics. Section508.gov remediation guidance

If you publish PDF and HTML versions, compare both with the approved figures. Accessibility work should not change the budget.

Budget-table checklist

  • Name the report, fiscal year and table clearly.
  • Identify units and explain dashes, blanks and negative values.
  • Mark column headers and row headers where applicable.
  • Check that each value is associated with the correct headers.
  • Verify totals, decimal points and signs against the approved source.
  • Read the table with a screen reader, including across page breaks.
  • Compare PDF and HTML versions after any revision.

The free SignalFeed PDF quick check can flag basic structural signals. Its table-header check does not establish that every table has correct header relationships. A person must examine those relationships. For further technical and visual checks, see PAC’s checking workflow.

This is a publishing checklist, not a finding that a budget document meets every accessibility requirement.
