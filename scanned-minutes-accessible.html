How to make scanned meeting minutes accessible

A scan can look perfectly readable while containing only pictures of words. Optical character recognition, or OCR, creates a text layer. That is a starting point: the resulting text still needs verification and accessible structure. Social Security Administration PDF testing guide

Find the best source

First ask whether an approved Word file or other editable source exists. Rebuilding from that source can avoid cleaning up recognition errors introduced by scanning. If only the scan remains, keep an unchanged original and work on a copy. Section508.gov describes OCR as the step needed when a PDF lacks readable text. PDF testing guidance

Run OCR with the correct document language. Then compare the recognized text with the visible pages. Pay particular attention to names, motion numbers, votes, dates, dollar amounts and words such as “not.” Do not let an AI system guess an illegible vote or silently rewrite the approved minutes; flag uncertainty for the records owner.

Add structure after correcting the text

Organize the document with headings for meeting sections, real lists where appropriate and correct tags for tables. Set its title and language, and check reading order. A screen reader should encounter the content in an order that preserves its meaning. W3C PDF techniques, including OCR, headings and reading order

A selectable sentence does not prove the whole file is accessible. You can use the free SignalFeed PDF quick check for initial flags, then examine the file with a validator and assistive technology. The quick check cannot judge the accuracy of your minutes or whether reading order makes sense. Quick-check scope

Review checklist

  • Preserve the original and identify the approved source.
  • Compare OCR text with every page, including handwritten additions.
  • Verify names, numbers, vote outcomes and negations separately.
  • Flag illegible passages for the records owner.
  • Check headings, lists, tables, title, language and reading order.
  • Listen to the final PDF with a screen reader and inspect any missing or repeated content.
  • Have the records owner approve the rebuilt version before publication.

This workflow recommends how to prepare and review a usable document. It does not decide whether an original record may be replaced or whether a particular file qualifies for a legal exception.
