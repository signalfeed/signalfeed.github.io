How to track tutoring sessions and invoices in Excel

How-to · Last reviewed November 2026 · Sources linked inline

If you tutor several students, three questions come up every month: how many hours did I teach, what did I invoice, and who still owes me? A single Excel workbook with three small tables answers all three. Here's how to build one yourself, with the exact formulas.

1. Make three tables

Create sheets named Clients, Sessions and Invoices. On each, type the headers, select them plus one row, and use Insert > Table. Name the tables the same as the sheets (Table Design > Table Name). Tables matter because new rows you type underneath automatically get the formulas.

  • Clients: ClientID, ClientName, ParentContact, Email, HourlyRate, Status
  • Sessions: SessionID, Date, ClientID, ClientName, Start, End, Hours, Rate, Amount, SessionStatus, InvoiceID
  • Invoices: InvoiceID, ClientID, InvoiceDate, DueDate, Total, AmountPaid, Balance, PayStatus

2. Let the session row fill itself in

In the Sessions sheet (row 2), these formulas look up the student's name and rate from Clients and work out hours and the amount. They use INDEX/MATCH, which works in every version of Excel for Mac and Windows:

  • ClientName: =IFERROR(INDEX(Clients!$B:$B,MATCH(C2,Clients!$A:$A,0)),"")
  • Hours: =IF(OR(E2="",F2=""),0,ROUND(MOD(F2-E2,1)*24,2)) (MOD handles sessions that cross midnight)
  • Rate: =IFERROR(INDEX(Clients!$E:$E,MATCH(C2,Clients!$A:$A,0)),0)
  • Amount: =IF(J2="Cancelled - not billable",0,G2*H2)

3. Total each invoice from its sessions

Give every session the InvoiceID it was billed on. Then in Invoices:

  • Total: =SUMIFS(Sessions!$I:$I,Sessions!$K:$K,A2)
  • Balance: =E2-F2
  • PayStatus: =IF(E2=0,"",IF(G2<=0,"Paid",IF(F2>0,"Partial","Unpaid")))

4. Add dropdowns

Excel doesn't accept a table reference as a dropdown source, so put your choices (for example Completed, Cancelled - billable, Cancelled - not billable) on a small hidden sheet, name that range (Formulas > Define Name), and use Data > Data Validation > List with =YourRangeName.

5. A one-glance summary

  • Outstanding: =SUM(Invoices!$G:$G)
  • Billable hours: =SUMIFS(Sessions!$G:$G,Sessions!$J:$J,"<>Cancelled - not billable")
  • Sessions not yet invoiced: =COUNTIFS(Sessions!$K:$K,"",Sessions!$A:$A,"<>")
