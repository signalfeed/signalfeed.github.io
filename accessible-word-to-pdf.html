Make a Word document accessible before you save it as a PDF

How-to · Last reviewed November 2026 · Sources linked inline

Start with the editable source file when you have it. Repair its structure, export with tags, then check the resulting PDF. These steps follow Microsoft's documented menus for Word on Windows and Mac; exact wording can differ between versions.

1. Use real heading styles

Select each section title and apply Heading 1, Heading 2 and so on from the Styles gallery on the Home tab, instead of making text bold and bigger. Use one Heading 1 for the document title and don't skip levels. Screen reader users jump between headings the way sighted readers skim.

2. Use real lists

Use the Bullets and Numbering buttons, not typed dashes or numbers. Word then tags them as lists in the PDF.

3. Add alt text to images and charts

Right-click the image, choose View Alt Text (or Edit Alt Text) and describe what the image tells the reader: “Map showing the closed section of Main Street between 3rd and 5th Avenue”, not “map”. For a chart, give the key numbers or put the data in a table. Mark purely decorative images (borders, repeated logos) as decorative.

4. Give tables a header row

Click in the table's first row, then on the Table Design tab tick Header Row. In Table Properties > Row, tick Repeat as header row at the top of each page. Avoid merged and split cells, and never use a table just to line things up on the page.

5. Write link text that makes sense alone

“Download the 2027 budget (PDF)” works; “click here” doesn't, because screen reader users often hear links out of context.

6. Set the title and language

Windows: File > Info > Properties, then fill in Title. Mac: File > Properties > Summary > Title. That title, not the file name, is what readers announce. Set the language under Review > Language on Windows, or Tools > Language on Mac.

7. Run the Accessibility Checker

On the Review tab choose Check Accessibility and fix everything in the Errors and Warnings lists. It catches missing alt text, missing table headers and hard-to-read color contrast.

8. Export with tags turned on

  • Word for Windows: File > Save As > PDF > Options, and make sure Document structure tags for accessibility is ticked.
  • Word for Mac: Command+Shift+S, set File Format to PDF, choose Best for electronic distribution and accessibility (uses Microsoft online service), then Export. Note that this option sends the document to Microsoft's online conversion service; it is not a local-only export.

Don't use “Print to PDF”: it throws the tags away.

9. Check the result

Drop the PDF into the free quick check to look for basic structural warning signs. Then inspect heading levels, reading order, table relationships and whether image descriptions convey the right information, and test navigation with a screen reader. Acrobat's Read Out Loud can be an extra listening check, but it isn't a screen reader.

Fix the template once

If your office produces the same kind of document every week (agendas, notices, newsletters), build these fixes into one Word template. A well-structured template gives each new document a better starting point; still check the content and the exported PDF each time. See how to make meeting agendas accessible.
